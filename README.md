# Wobby's CPU_RT
An improvement over my previous CPU Raytracer. The main goal for this one is a cleaner API and the ability to render triangles.

## Goals

1. Triangle rendering
2. Model loading via Assimp
3. Fully texture driven materials
4. Multithreading via thread pools
5. SIMD acceleration
6. JSON configuartion and scene descriptor system
7. Vulkan RT scene previewer for rapid iteration
